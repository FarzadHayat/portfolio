This was my Capstone project, done with Antero Software. I was the QA Lead. My goal was to find out how well AI agents can automate QA work, and to build a way to measure it.

First I researched GitHub Copilot and other AI tools. I built a prototype Copilot workflow in VS Code that connects to Jira through the Atlassian MCP server. It pulls user story details and acceptance criteria from Jira tickets, expands them into test cases with preconditions, posts the test cases back to the ticket and generates runnable Cypress and Playwright tests. This removed a lot of switching between tools, and made it easier to turn requirements into automation scripts.

My teammates built a custom TestGen CLI tool. My job was to evaluate how well different AI agents write Playwright E2E tests. I used a custom benchmark dataset that runs on the **Harbor framework**. It has ten tasks based on common web app patterns, such as multi-step checkout flows, complex form validations, drag-and-drop interactions and GitHub API mocking.

Pass/fail alone is not enough, so I designed a reward model with seven metrics:

1. **Functional correctness:** does the test suite pass reliably?
2. **Selector quality:** does the agent use resilient, semantic locators (e.g., `getByRole`, `getByText`)?
3. **Auto-waiting:** does it wait on state instead of using hardcoded timeouts?
4. **DRY code quality:** is the code modular, without duplicated magic strings and repeated action blocks?
5. **Page Object Model usage:** does the agent use the pattern correctly?
6. **Mutation score:** measured with Stryker, to check the tests actually catch regressions.
7. **Flakiness:** do the tests give the same result across multiple runs?

The benchmark compared Anthropic's Claude Code, our team's TestGen CLI tool and an Oracle baseline. The report gave Antero Software real data on what AI can and can't do in test automation today.
