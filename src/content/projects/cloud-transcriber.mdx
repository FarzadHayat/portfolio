A web app where you upload audio or video and get a transcript back. It runs on AWS and uses the open-source Whisper speech recognition model. Uploaded video is converted to MP3 with FFmpeg, Whisper transcribes the audio, and the transcription service scales up and down with the workload. Transcripts are stored in a database so users can read them later.

It is deployed on AWS in ap-southeast-2. These are the parts:

- **Route 53 and API Gateway:** map the custom domain and route HTTPS traffic to the EC2 instance.
- **EC2:** Docker containers for the Express REST API and Nginx (web client and reverse proxy).
- **ElastiCache:** Memcached to speed up API responses.
- **ECS:** runs Whisper and auto-scales on the total duration of audio waiting in the SQS queue.
- **Lambda:** one function extracts audio from uploads with an FFmpeg layer and records the duration. Another periodically publishes the queued audio duration to CloudWatch.
- **S3:** buckets for media, extracted audio and transcripts.
- **SQS:** one queue for finished audio extraction, one for transcription jobs.
- **Cognito:** login with Google OAuth.
- **CloudWatch:** logs, Lambda schedules and ECS scaling triggers.
- **Secrets Manager and Parameter Store:** DocumentDB credentials and config.
- **DocumentDB:** audio file and transcript data.
